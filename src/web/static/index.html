Individual trips

The investigation view: narrow to the records a quality rule flagged, then open one to see its flags beside the raw CSV text it was parsed from.

Unlike the aggregate panels, this list applies no flag exclusions - hiding flagged rows here would hide the point of the view. Paged in IRIS with TOP and %VID; there is no LIMIT/OFFSET in IRIS SQL and the idiom costs more the deeper you page, so filter rather than paginate. Rule names come from Taxi.mask_names, a Python function running inside IRIS.

Aggregate in IRIS, or in Python?

Both halves compute the same table. One lets IRIS GROUP BY and returns the finished result; the other streams every matching trip into Python and accumulates it in a dict. The current filters apply to both. The second half is slow on purpose - it is the thing being measured.
